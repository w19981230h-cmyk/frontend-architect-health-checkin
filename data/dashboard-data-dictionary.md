# 十万人区域报表数据口径

区域总人数 100,000 人为用户指定基数。其他流转明细按业务规则生成，未接入医院真实业务系统；页面保留模拟数据标识。统计周期 2026-07-01 至 2026-07-31。

## 单一数据源

js/dashboard-latest-data.js 生成 100000 条唯一患者记录、20900 条病例、15000 条管理周期、1095 条预警、2740 条转诊。所有模块从同一底表关联汇总；data/dashboard-reconciliation.json 保存本次对账快照。三家机构人口分别 40,000、35,000、25,000，不重叠。

## 筛查与管理

筛查流转：100,000 → 60000 → 13720 → 11100 → 9590 → 8958。各步转化率使用前一步为分母。未筛 40000，筛查未见异常 46280，异常但不符合入组 2620，符合但未入组 1510，其中超期 453。

应管理 24000 = 在管 21000 + 未在管 3000。在管 21000 = 本期入组在管 8958 + 历史及其他来源在管 12042。本期入组 9590 = 在管 8958 + 已退出 632。

当前应管理包含本期符合入组条件人群和历史及其他来源。每人唯一主责机构、唯一管理等级；机构合计、等级合计等于区域应管理人数。规范管理率为规范管理人数 / 规范管理可评价人数；未分级暂不评价。

## 成效

应评价 20900 例 = 可评价 18450 + 待评价 2450。每个患者与病种组合一条病例，合并疾病可使病例数超过人数。目标达成、改善、稳定、恶化四类互斥，合计等于可评价病例，待评价病例无结果。机构和病种分别汇总均与区域一致。

规范管理按人、成效按患者病种病例，二者评价范围和单位不同；规范管理可评价 18880 人不能与成效可评价病例相混淆。生成的成效标签用于联调，不表示实际临床疗效。

## 风险

高危预警涉及 400 位红色管理患者。事件 1095 = 已闭环 780 + 已处置未闭环 120 + 待处置 195。到期事件 920，及时处置 866；及时处置率与闭环率均以到期事件为分母。未闭环包括待处置和已处置待结果确认；高危未闭环人数按人去重，不能把事件数当人数。机构关注提示和弹窗来自相同预警记录。

## 转诊

上转：1550 → 1454 → 1341 → 1264（转出、接收、到院、诊疗反馈完成）。下转：1190 → 1098 → 1004 → 942（转出、接收、交接、首次随访完成）。各方向按患者去重，当前每位患者每方向一条记录；两方向可能重叠，不直接相加为唯一患者人数。

阶段率用上一步作分母，闭环率用转出人数作分母；平均接收时长由每条已接收记录的时间差计算。各完成阶段时间递进，未完成阶段时间为空。诊疗反馈及随访完成并不新增筛查入组人数。

## 校验与范围

运行 node scripts/verify-dashboard-latest.cjs 验证十万人基数、唯一记录、外键、嵌套流转、机构/分层/来源合计、成效守恒、风险明细和汇总、转诊时间及比率。当前仅有上述月份和三家机构，尚未生成科室、个人及其他月份数据，查询不支持的范围仍会提示。
